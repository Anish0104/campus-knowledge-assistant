Your questions

The form sends your question, campus, and program to this application's server. The current local setup uses Ollama to process questions with retrieved document passages.

Browser storage and external services

This frontend does not save conversation history in browser storage. Fonts load from Google Fonts. Those requests disclose connection information, such as your IP address, to that service.
